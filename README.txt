THE BESTIARY — ILLUSTRATED WEB APP

This edition includes the original black-and-white Men of Letters-style Bestiary artwork
for all 36 creature entries.

FEATURES
- 36 illustrated Bestiary entries
- Dossier thumbnails on the archive cards
- Full illustrated dossier inside each creature entry
- Full-screen dossier viewer
- Search across names, lore, signs, types, and weaknesses
- Alphabetical navigation
- Creature-type filtering
- Browser-saved favorites
- Favorites side panel
- Random Entry button
- Personal Hunter Notes saved in browser local storage
- Responsive layout for desktop, tablet, and phone

HOW TO USE LOCALLY
Keep index.html and the assets folder together.
Open index.html in a modern web browser.

HOW TO PUT IT ONLINE
Upload the entire folder — index.html plus assets — to a static website host.
GitHub Pages, Netlify, Cloudflare Pages, and ordinary web hosting can all serve it.

IMPORTANT
Favorites and personal Hunter Notes are stored in the browser on the device being used.
They are not synced between devices yet.
